## Main features

- TikTok LIVE chat, likes, gifts, follows, joins and viewer metrics
- Live / maximum viewer counters
- Top liker and top gifter rankings
- Recent gifts and follower lists
- OBS/browser-source widgets with customizable appearance
- Movable and resizable desktop overlay windows
- Profile avatars and large profile preview
- PDF reporting
- Event sounds and Turkish text-to-speech support
- Supabase-based global accounts
- Email/password and Google sign-in
- Cloud-synced user settings
- Windows installer and macOS DMG builders

## Requirements

- Python 3.11 or 3.12 is recommended for source builds
- An EulerStream API key for LIVE data
- Internet connection

## Run from source

```bash
python -m venv .venv
```

Windows:

```powershell
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

macOS:

```bash
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

## Build installers

Windows:

```text
BUILD_RELEASE.bat
```

macOS:

```text
BUILD_RELEASE.command
```

Or run the cross-platform builder directly:

```bash
python BUILD_RELEASE.py
```

Windows builds must be produced on Windows and DMG builds on macOS.

## Release workflow

The repository includes `.github/workflows/release.yml`.
From **Actions → Build Release → Run workflow**, enter a version such as `v53`.
GitHub will build both platforms and publish the installer files to the Releases
page. The download links above always point to the latest release.

## Security

Do not commit Euler API keys, passwords, Supabase secret/service-role keys,
OAuth client secrets, or local session data. The Supabase key shipped in
`cloud_config.py` is intentionally a publishable client key.
