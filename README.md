# RπM Studio

RπM Studio is a desktop control studio for TikTok LIVE creators.

## Downloads

- Windows: https://github.com/Wyzuee/RpiM-Studio/releases/latest/download/RpiM_Studio_Setup.exe
- macOS: https://github.com/Wyzuee/RpiM-Studio/releases/latest/download/RpiM_Studio_macOS.dmg

## Features

- LIVE chat, likes, gifts, follows, joins and viewer metrics
- OBS/browser-source widgets
- Top liker and top gifter rankings
- Profile avatars and enlarged profile preview
- PDF reports
- Event sounds and Turkish text-to-speech
- Supabase global accounts
- Email/password and Google sign-in
- Windows and macOS release builders
